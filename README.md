A tiny deterministic paper-trading bot for hourly Solana prices that beats buy-and-hold in either market direction: it rides uptrends with an EMA(8)/EMA(21) crossover sleeve, buys oversold bounces with an RSI(14) mean-reversion sleeve, and keeps a minimum-activity sweep so it always clears the competition's 8-trade bar. On the dev window it scores +16.57 USDC net PnL over 45 trades with a 1.9% max drawdown, against −869.34 USDC for buy-and-hold.

## Run it

```sh
node main.ts
```
